# Flight-Data-Analysis
This project explres an airline dataset using Python in Jupyter Notebook to uncover insights about flight perfomance, passenger behavior, and customer loyalty patterns.
# Objectives
Analyze flight punctuality trends (on-time, delayed, cacelled).
Identity factors influencing flight delays and cancellations.
Examine customer demographics(age, gender, continent).
Segement passegers by loyalty based on recency and frequency of flights.
# Tools & Libraries
Python - Data Analysis.
Pandas - Data cleaning and tranformation.
Numpy - Statistical calculations.
Datetime - Date formating & feature extraction.
Matplotlib / Seaborn - Visualization.

# Analysis Steps
Data Cleaning - (Replaced spaces and symbols in column names, standardized format).
Demographic Analysis - (Calculated male/female counts and average passenger age.
Performance Analysis - (Measured cancelation and delay rates per day, age group, and continent
Time-Series Trends - (Tracked daily delay trends over time to identify high risk days).
Loyalty Segmentation - (Created loyalty groups(High, Moderate, Low) based on passenger flight istory).
Visualization - (Used bar charts and line plots to highlight insights clearly)
# Key Insights
Delay and cancellation rates by day, continent, nd age group.
Weekly and daily delay trends.
Monday flights had the highest cancellation rate ~ 33.8%.
Middle aged passengers flew frequently and had fewer cancellations.
